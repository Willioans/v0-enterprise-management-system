🚀 ANTES DE PRODUCCIÓN (IMPORTANTE)
═══════════════════════════════════════════════════════════════════════════════════

PASO 1: CONFIGURA FIRESTORE RULES
├─ Ve a Firebase Console
├─ Firestore Database > Rules
├─ Copia las reglas de SECURITY_GUIDE.md
└─ Publica cambios

PASO 2: RESTRINGE API KEY A DOMINIOS
├─ Google Cloud Console
├─ APIs > Credenciales
├─ Tu API Key > Restricciones
├─ Agrega:
│  ├─ localhost:3000 (desarrollo)
│  ├─ tudominio.com (producción)
│  └─ www.tudominio.com
└─ Guarda cambios

PASO 3: HABILITA MFA Y VERIFICACIÓN
├─ Firebase > Autenticación > Configuración
├─ Habilita "Verificación de email"
├─ Habilita "Autenticación de múltiples factores"
└─ Guarda cambios

PASO 4: CONFIGURA VARIABLES EN VERCEL
├─ Vercel Dashboard > Proyecto > Settings
├─ Environment Variables
├─ Agrega todas las NEXT_PUBLIC_FIREBASE_*
├─ Marca como Production
└─ Deploy
