INSTRUCCIONES DE DEPLOYMENT
=================================================================

PASO 1: Preparar el proyecto
```bash
npm install
npm run validate-security
```

PASO 2: Verificar Firebase
- Asegúrate de que las variables de entorno están en Vercel
- Configura las reglas de Firestore para seguridad
- Configura CORS en Firebase Console

PASO 3: Deploy a Vercel
```bash
vercel deploy --prod
```

PASO 4: Configurar dominio
- Ve a Vercel Dashboard
- Configura tu dominio personalizado
- Configura el certificado SSL

PASO 5: Monitoreo
- Habilita Analytics en Vercel
- Configura alertas de error
- Revisa logs regularmente
